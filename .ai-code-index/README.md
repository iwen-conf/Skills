# .ai-code-index — arc-idx Context Engine Home

This directory is the per-repository home of the `arc-idx` context engine
(a compiled Go CLI, source in `tools/arc-idx/`, installed at `~/.local/bin/arc-idx`).
The legacy `*.sh` scripts that used to live here are gone; `arc:idx` bans them.

## Contents

| file | tracked | purpose |
|---|---|---|
| `config.json` | yes | ignore rules + profile globs for this repository |
| `tags.json` | no | ctags symbol table, regenerated by `arc-idx index` |
| `daemon.log` | no | background indexer log |
| `daemon.pid` | no | background indexer pid file |

Zoekt shards live outside the repo at `~/.cache/ai-code-index/zoekt/<repo>/`
(override with `AI_CODE_INDEX_DIR` or `config.json.index_dir`).

## Daily usage

```bash
arc-idx index                                  # full rebuild (zoekt + ctags, parallel)
arc-idx search 'f:\.go$ Builder' --format json # indexed text/regex search
arc-idx symbol UserService --kind struct       # symbol lookup
arc-idx ast --lang go 'func $N($$$) error'     # structural search (ast-grep)
arc-idx files SKILL --profile skills           # file discovery
arc-idx stats --profile code                   # inventory
arc-idx doctor                                 # health + freshness report
arc-idx daemon start|status|stop               # incremental background indexing
```

See `Arc/arc:idx/SKILL.md` for the full agent contract.
