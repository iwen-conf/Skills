# CNB NPC 协作

| 情况 | 动作 |
| --- | --- |
| 复杂任务需要专家但未授权委派 | 只推荐候选与职责，不发消息 |
| 已明确授权 NPC、任务与范围 | 搜索核实角色，准备并发送任务 |
| 搜索无匹配或发送状态未知 | 返回缺口，不假设召唤成功、不重复发送 |

通过 npc-search 模式查真实 `slug`/`name`，正确召唤格式为 `@{slug}({name})`，如 `@npc/code-reviewer(代码审查员)`；只提及则用反引号包裹，避免召唤。

交付包写清目标、相关文件/分支、范围与非目标、约束、验收、写入归属；并行工作不得同时修改同一文件。用 api 模式当前 Issue/PR 评论路径发送，执行[运行合同](../../../docs/cnb-runtime.md)。返回真实消息/任务标识和发送状态；召唤成功不等于子任务完成。

等待应限定本次任务窗口；超时返回 pending 与跟进标识，不无限等待，不因超时重新委派。撤回或收回任务需使用平台已核实能力并遵守授权，不能仅口头宣称取消。
