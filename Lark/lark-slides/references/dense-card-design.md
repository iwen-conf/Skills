# 信息密集报告的可选设计

仅用于适合逐行阅读的报告页；用户模板和明确风格优先。封面、分节、引言、大数字页按内容独立设计。

- 卡片按内容层级组成网格，视觉锚点 + 标题 + 完整说明；不固定卡片数量或字数，不为填满页面增写事实。
- 可用方角、半透明填充、无边框；不增加无意义贴边窄条。同级卡片复用配色，强调色只用于信息重点。
- 文本、真实图片、原生图表按信息关系分配空间。图表有数据来源，缺素材按 asset-planning 的原生 fallback。
- 页面边距可从 40px 起，卡片内距按字号留足，组间可从 20–40px 起；以 960×540 内不溢出、可读为准。
- 正文通常左对齐，数值按列对齐；同级字体、行距一致。可选思源黑体，标题 28–36pt、正文 12–14pt、注释 10–12pt；不可为塞字压低可读性。
- 保持一致的背景、主色和强调色。蓝橙搭配本身并不违规，以品牌、对比与色彩角色为准。

上述均是设计起点，不替代 XML schema、xml_lint 和写后验证。
