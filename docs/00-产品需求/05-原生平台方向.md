# 原生平台方向

用户决定（2026-10-06）：「我们不再追求跨平台，现在追求原生」。

新客户端以目标平台原生 SDK、UI、生命周期及系统体验为目标，不再以一套跨平台 UI 或最大代码复用率为选型标准。Web 仍是 Web；后端、HTTP 合同及业务语义可复用，但不能据此强迫客户端共用 UI 框架。

既有跨平台项目的维护不等于已授权整项目重写；新增独立原生目标按原生路线实施，嵌入既有项目的局部改动须保持可交付和明确迁移边界。用户后续明确指定其他技术时，以该任务约定为准。

本轮更新 Arc 共享选型、前端/主题、规划及验证规则，移除移动 Expo、桌面 Tauri、小程序 Taro 的默认脚手架，并同步鸿蒙原生口径和本机安装。不批量删除外部工具，不改变标准协议中的跨平台互操作含义。

验收：相关技能加载同一原生合同；Web 库不要求安装到原生项目；原生目标有对应验证方式；包校验及安装引用回读通过。
