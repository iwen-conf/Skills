# Interface System: Linear & Apple Notes Standard (UX x DX x AX)

Every interface decision must simultaneously improve **User Experience (UX)**, **Developer Experience (DX)**, and **Agent Experience (AX)** without breaking existing workflows.

## 1. Self-Evident Layout Over Crutch Copy

- **Squint & Strip Pass**: Delete marketing slogans, instructional banners, helper subtitles under section headers, empty-state essays, decorative icon circles on metric cards, and redundant status pills. If hierarchy feels unclear without prose, fix alignment, spacing rhythm (`4/8/12/16/24/32px`), or progressive disclosure—never add explanatory copy.
- **Single-Cue Framing**: Use **at most one** boundary cue per container (`1px` hairline border OR subtle surface elevation step—never stacked `border + drop-shadow + tinted card`).
- **Focused Canvas**: One primary action per screen; move secondary actions into context menus, sheets, or `Cmd/Ctrl+K` command palettes.

## 2. Native Toolkits & Viewing-Distance Ergonomics

- **Native Direction**: `Swift + SwiftUI` (`apple-native.md`), `Kotlin + Jetpack Compose` (`android.md`), `ArkTS + ArkUI` (`harmonyos.md`), `React 19 + TypeScript + Tailwind CSS v4 + shadcn/ui` (`web-frontend.md`; Vite + TanStack Router for Admin/C-side, Astro + React islands for marketing sites). Never ship web wrappers as native apps or add competing UI/state libraries.
- **Existing-Product Direction Lock**: When adding a surface to a mature app, inspect sibling components first and inherit their container, token, typography, and motion vocabulary; never invent an unrequested style or propose wholesale platform restyling (e.g., Liquid Glass / Material You) on a coherent existing native app unless explicitly asked.
- **Touch / Mobile (20-40 cm)**: Minimum **44pt x 44pt** (`44px x 44px` / `48dp`) hit targets with **`>= 8px` gap between adjacent interactive controls**; thumb-zone primary controls; **never rely on hover-only interactions** (guard pointer hover with `@media(hover:hover)` / `[@media(hover:hover)]:hover:...`, set `touch-action: manipulation`, and `overscroll-behavior: contain` on modals/drawers); zero horizontal overflow at `320px`; foldable split-pane and hinge avoidance.
- **Pointer / Desktop (50-100 cm)**: Dense scannable rows, full keyboard traversal, crisp `:focus-visible` outlines, deterministic shortcuts.

## 3. Executable Visual, Motion & State Matrix

- **Typography**: System fonts (`SF Pro`/`NY` on Apple, native sans elsewhere). Floor **>= 11pt** native / **12px** metadata / **14px** body; **ban Ultralight/Thin weights**; cap prose at `max-width: 65ch`; tighten large headings (`-0.02em`); `flex-shrink: 0` on avatars/icons; enforce `tabular-nums` on counts, amounts, dates, and table columns; reflow horizontal groups into vertical stacks cleanly under Dynamic Type and `200%` zoom.
- **Color, Theme & Taste Anti-Slop**: Single semantic token layer across Light/Dark (`>= 4.5:1` contrast, target `7:1`; never color-only status). Light-mode nested surfaces require `>= 4%` lightness step; dark mode uses `color-scheme: dark` on `<html>`, subtle white-alpha overlays (`0.02–0.05`), explicit `<select>` colors, and `#f0f0f0` / `85%` text over harsh `#ffffff`. **Ban default violet/lavender/purple-gradient AI palettes**, scroll-reveal fade-ins on every card/section, text parallax, scroll-jacking, and random blinking. Keep box nesting `<= 2` levels with one button/card/radius/link scale; match register to business kind (shaders/dark heroes for tech/software only; real photography + flat grounds for physical/service/place). Restrict translucent blur / Liquid Glass strictly to floating chrome; concentric radii `R_outer = R_inner + padding`.
- **Surfaces, Card Alignment, Media & Copy**: Same-row cards share height and bottom-aligned CTA baselines; never tail-truncate metric/label footers with `…` (compact instead); keep `<= 3` text styles inside a small card; never draw illustrative scenes in inline SVG. Give `<img>` explicit `width`/`height` (or `aspect-ratio`), `loading="lazy"` below fold, and `fetchpriority="high"` on hero; prefer `<video autoplay muted loop playsinline>` over GIF. Use `Intl.DateTimeFormat` / `Intl.NumberFormat` / `Intl.PluralRules` (absolute date after 7 days) and `translate="no"` on brand/code tokens; sentence-case headings, no `!` on routine success ("Saved"), no "Oops!" or passive errors, zero AI buzzwords (`Elevate`, `Seamless`, `Unleash`, `Delve`, `Next-Gen`).
- **Motion & Physics Craft**: Frequency decides: never animate keyboard-initiated changes or high-frequency controls (`100+/day`). Use strong curves (`--ease-out: cubic-bezier(0.23, 1, 0.32, 1)`, `--ease-in-out: cubic-bezier(0.77, 0, 0.175, 1)`, `--ease-drawer: cubic-bezier(0.32, 0.72, 0, 1)`), `< 300ms` transitions (modals/drawers/toasts `<= 500ms`), and **never `ease-in` on UI enter/response** (short exit only). Prefer interruptible CSS transitions + `@starting-style` over `@keyframes`; subtle press `scale(0.97)` at `160ms`; skip tooltip delay on consecutive toolbar hovers. Never enter/exit from `scale(0)` (use `scale(0.95)` + `opacity: 0`), anchor popovers to trigger `transform-origin`, and set `initial={false}` on toggles/tabs. Animate `transform`/`opacity` only (**ban `transition: all`**); never drive child transforms via parent CSS vars or frame-rate React state (`ref.current.style` instead); keep animated `blur() <= 20px`; autoplay loops `> 5s` need pause controls and rest under `prefers-reduced-motion`.
- **AX, Focus, Forms & Worst-Case Stress (`break-ui`)**: Semantic primitives (`<button>`, `<a href>`, `<input>`, `<label>`) with `aria-label` on icon-only buttons, `aria-hidden="true"` on decorative icons, and `aria-live="polite"` on async updates; drag/swipe gestures need click + keyboard alternatives. **Ban `outline-none` without `focus-visible:ring-*` replacement**, **ban `tabIndex > 0`**, **ban `user-scalable=no`/`maximum-scale=1`**, and **never block paste (`onPaste` + `preventDefault`)**. Sticky headers/overlays must never occlude focused elements (`scroll-margin-top` + skip link + hierarchical `<h1>`–`<h6>`); forms require `autocomplete`, `name`, right `type`/`inputmode`, `spellCheck={false}` on codes/emails, whole-target checkbox/radio labels, enabled submit until flight, unsaved-change guard, and no mobile `autoFocus`. Stress-test hostile inputs: long unbroken emails/URLs (`overflow-wrap: anywhere`), CJK / RTL (`dir="auto"`) / stacked diacritics / ZWJ emojis (`👩🏽‍💻`, avoid `.charAt(0)`/`.length`), edge numbers (`0`, `1`, `1M`, `0.1+0.2`, `null`/`NaN`), `12+` tags collapsing to `+N`, `0`/`1`/`1000+` items (virtualize `> 50`), and 404 avatar fallback + `object-fit: cover`. Verify `default`, `loading`, `empty`, `error` (`aria-invalid` + `aria-describedby` + focus first invalid), and `disabled` states across Light/Dark themes.

## 4. Anti-Overlap Layout, Semantic A11y & Live Visual Verification

- **Layout Flow (`防重叠 / 防撑破`)**: Build card and page flow exclusively with CSS Grid or Flex + `gap`. **Ban `position: absolute` in normal document flow** and **ban negative margins (`-m*`) for stacking cards or sections**. **Ban fixed `height` on text/card containers** (use `min-h-*`); enforce `min-w-0` plus wrapping/truncation (`break-words` / `truncate`) inside flex/grid items. Restrict `z-index` strictly to preset semantic tiers (dropdown / sticky / overlay / modal / toast — ban arbitrary `z-[999]` arms races). Explicitly reject "overlapping / broken-grid" stylistic prompts from third-party `frontend-design` forks in product UI.
- **Semantic HTML Over ARIA Faking (`防 div 当按钮`)**: Action -> `<button type="button|submit">`, navigation -> `<a href>` / router `<Link>`, input -> `<input>`/`<select>`/`<textarea>` paired with `<label>` (prefer `shadcn/ui` primitives). **Ban `<div onClick>`, `<span onClick>`, `<a href="#">`, and role-faking `<div role="button" tabIndex={0}>`**; use ARIA only when no native HTML element exists. Cover `default`, `hover`, `:focus-visible`, `disabled`, `loading`, `empty`, and `error` states on interactive controls.
- **Closed-Loop Browser Verification (`改完 UI 必须浏览器自证`)**: Never report a UI task complete from source edits alone. Render the live page across **`375px` (mobile), `768px` (tablet), and `1280px` (desktop)** viewports via `agent-browser`, Playwright, or Chrome DevTools MCP, verifying screenshots, zero horizontal overflow (`scrollWidth <= clientWidth`), non-overlapping sibling `boundingBox()` geometry, and keyboard focus traversal.
- **Screenshot Iteration Protocol**: Preserve diagnostic user labels ("丑 / 怪 / 突兀 / 挤") and lock `target` / `preserve` / `evidence` before edits. Close alignment/spacing fixes with measured before/after box geometry (`getBoundingClientRect` / `boundingBox` + viewport width) and report `checked N / changed M / left K` over sibling consumers. If tuning a visual value fails on try #2, render 3 labeled side-by-side candidates instead of blind single-value retries.
