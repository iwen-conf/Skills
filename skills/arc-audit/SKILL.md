# arc-audit

Read-only evaluation. Mutate zero source files, configs, or `.arc/arc.db` records.

## Protocol

1. **Diff, Code-Rot, Reuse & Stack Audit**: Rank findings `CRITICAL > HIGH > MEDIUM` with exact `file:line`, failure/exploit scenario, and minimal remedy against `../_shared/contract.md` and matching stack specs (`ui-system.md`, `web-frontend.md`, `debugging.md`, `go-conventions.md`, `api-contract.md`, `android.md`, `harmonyos.md`, `apple-native.md`).
   - **Conditional Risk & Hygiene Traps (`debugging.md`)**: Treat CI/release/auth/billing/installer/deletion paths as deep-audit tiers regardless of diff size; flag duplicated derivations, non-atomic user file writes, broad deletion matchers, unreached-helper/literal-string tests, never-shipped migrations, unreachable security-PR deps, and unverified deletions without behavior classification (`folded` / `redundant` / `removed`).
   - **Web Frontend (`web-frontend.md`)**: On new Web diffs, verify zero hand-written `fetch`/`useEffect` data fetching, zero hand-edited generated files (`src/api/generated/`, `routeTree.gen.ts`), zero `framer-motion`/`antd`/`@tanstack/zod-adapter`/`@astrojs/tailwind`/`nuqs` in new projects, zero MSW in production bundles, zero `localStorage` auth tokens, zero static `<div|span onClick>`, role-faked `<div role="button">`, or `<a href="#">`, zero `transition-all`, `outline-none` without `focus-visible` ring, `tabIndex > 0`, paste-blocking `onPaste`, or zoom-disabling viewport meta, zero flow `position: absolute`/negative-margin stacking/fixed-height cards missing `min-h`/`min-w-0`, zero `< 44px` hit targets or `< 8px` target gaps, zero hover-only controls or arbitrary `z-index`, zero missing `Intl.*`/`<img>` dimensions/virtualization for `> 50`-item lists or `break-ui` overflow, and zero `oxlint-disable` bypasses; output concrete UI polish findings in a `| Before | After | Why |` table.
   - **Go (`go-conventions.md`)**: Explicitly audit:
     - **`iwen-example` Explicit Architecture**: Plural package layout (`domain/{entities,events,filters,repositories,services}`, `infrastructure/gateways/persistence/postgres/{models,repository}`, `support/*`, `wire/*`), strict import bans, `Contract`/`Params`/`Results`/`Service`/`Repository`/`Model`/`Engine` naming (zero `Port`/`Adapter` or `var _ Contract = (*Service)(nil)`).
     - **Composition Over Inheritance & Zero `any`/`interface{}` Strong Typing**: Ban `BaseService`/`BaseRepository`/`BaseEntity` pseudo-inheritance and embedded `*sql.DB`/`sync.Mutex`/SDK leaks; strictly ban `any` and `interface{}` dynamic types anywhere in Go (enforce concrete `struct`s, `dto/responses` `Base` struct-literal embedding, and narrow consumer interfaces at the 4 explicit seams only; zero `gin.H`, `map[string]any`, `[]any`, `Response[T any]`, `NewXxxResp` wrappers, or `entity.ToDTO()`).
     - **Budgets, Reuse & Go Standards**: `.go <= 1200` lines (`service_*.go <= 400`, `controllers/* <= 600`, `<= 2` private funcs per workflow file), stdlib/`utils-pkg`/`arc idx` reuse, `pkg/<topic>` extraction (ban `util`/`common` & ceremonial 1-line getters), `MixedCaps` typed enums, `errors.Is`/`errors.As` + log-once, `TxManager` CAS SQL, and `zap` hygiene.
     - **Comment Hygiene**: `struct` field comments inside `struct`, 3-part `请求体`/`响应体` headers (DTO-level on `controllers`), single-line `// 函数名 函数功能` on middlewares and `TestXxx`, internal `// 1. xxx` steps, and `只补缺失，不动已有`.
2. **Security Scan**: Run `python3 ~/.agents/skills/arc-audit/scripts/security-scan.py . --task-slug <slug>` for secret, SAST, lockfile, and OpenAPI checks.
3. **Agent Host, Supply-Chain & Maintainability Health**: Verify `~/.claude/skills`, `~/.codex/skills`, `~/.grok/skills`, `~/.gemini/config/skills`, `~/.cursor/skills`, and `arc capabilities --json` without printing secret values. Flag unpinned third-party skills/plugins/MCPs, wildcard `allowedTools`/permission-skip flags or API base-URL overrides in tracked files, hollow verifier wrappers, stale verifier cache paths, broken local doc links, and concentrated 2-week `fix:` chains lacking a durable gate.
4. **Data Provenance & Anti-Fabrication Audit (`真实数据与依据核查`)**: Flag any hardcoded fake data, static mock fallbacks, fabricated metrics, or unverified claims in code/UI as `CRITICAL`/`HIGH` defects. In the audit report itself, never invent line numbers, unread code behavior, coverage/perf metrics, or test outcomes—every finding and number must cite verified `file:line` or live command output, explicitly marking unexecuted checks as `NOT_RUN` / `BLOCKED`.
